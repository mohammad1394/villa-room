# Villa Room 🏡

Villa Room is a villa rental and reservation web application built with Next.js. It provides a user-friendly interface
for discovering villas, exploring property details, and managing reservations.

## ✨ Features

- Browse and explore villas
- Search and filter villas
- View detailed villa information
- User authentication and account management
- Villa reservation management
- User reviews and ratings
- Discount and promotional listings
- Admin dashboard for managing villas and reservations
- Responsive design for desktop, tablet, and mobile devices

## 🛠️ Tech Stack

- **Next.js** — React framework
- **React** — User interface
- **TypeScript** — Type safety
- **Tailwind CSS** — Styling
- **MongoDB** — Database
- **Mongoose** — MongoDB object modeling

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- MongoDB

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/villa-room.git
   ```

2. Navigate to the project directory:

   ```bash
   cd villa-room
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the root directory and configure your environment variables.

   ```env
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_jwt_secret
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
